# 🛰️ Space Colony Walk — 歩ける・住める・稼げるスペースコロニー

**直径 6.5 km・全長 30 km のオニールシリンダーの内側を、ブラウザだけで一人称で歩き回る 3D 世界。**
頭上には対岸の街、遠くの地面は壁のようにせり上がり、足元のガラスの向こうには宇宙が回っている。

インストール不要・画像素材ゼロ・ビルド不要。**すべてコードで生成**しています（Three.js + 自作シェーダー）。

> *A fully walkable O'Neill cylinder (6.5 km wide, 30 km long) that runs in your browser. No build step, no image assets — terrain, a 300 km² city, ocean, whales, a monorail and even the sky are all procedurally generated.*

## 🎮 遊び方

**普通にプレイ**（目的: 稼いで豪邸を買う）と**開発者モード**（飛行・ワープで自由に探索）をタイトル画面で選べます。セーブデータは名前つきで複数持てます（ブラウザの localStorage）。

| キー | 操作 |
|---|---|
| `W A S D` / マウス | 移動 / 視点 |
| `W` 二回押し | 走る |
| `Space` | ジャンプ（開発者モード: 二回押しで飛行 ⇔ 歩行） |
| `Shift` | 泳いでいるとき潜る |
| `C` | 車を呼ぶ |
| `E` | 乗る・降りる・明かり・ベッド・売地を買う |
| `M` | 全体マップ（モノレールの駅も表示） |
| `T` | 押している間、時間を早送り |
| `V` / `R` | 画質 / 解像度の切り替え |
| `P` / `K` | 文字を消す / スクリーンショット保存 |
| `Esc` | 一時停止・上書き保存 |

**おすすめの順路:** 砂浜を歩く → 桟橋の先の飛込み板から海へジャンプ → モノレールで窓を渡る → エレベーターで宇宙港へ → 採掘船で隕石を掘る → 豪邸を建てて屋上から景色を眺める

## 🚀 動かし方

```bash
git clone https://github.com/yosshii689/SpaceColony.git
cd SpaceColony
python -m http.server 8000      # 何でもよい。静的サーバーで配信するだけ
# ブラウザで http://localhost:8000 を開く
```

`index.html` をそのままブラウザで開いても動きます。WebGL2 対応のブラウザが必要です。

## 🔧 中身が気になる人へ

- **円筒座標 (θ, z, h)** で世界を管理し、「上」は常に回転軸の方向。重力は高さに応じて弱まり、軸に近づくと無重力になる
- 建物・地形・樹木・海底・クジラの体・夜景まで**すべて手続き生成**。乱数は固定シードなので毎回同じ街
- 窓の奥の部屋、水面の光の網目、壁の模様は**シェーダーで描画**（画像ファイルなし）
- 30 km の世界を滑らかに描くため、近景・中景・遠景を分け、画面の外の塊は描かない
- 当たり判定は壁・屋上・桟橋の柵・駅のホームドアまで。1歩が大きくても薄い柵を突き抜けない

設計の経緯と全仕様は [`計画書.md`](計画書.md)、ロジックのテストは `node tests/core.test.cjs` / `node tests/game.test.cjs`。

```
index.html        起動画面・UI
js/core.js        円筒座標・重力・歩行／泳ぎ／飛行
js/terrain.js     地形・水・ゾーン
js/city.js        建物・樹木・車の形・桟橋・当たり判定
js/post.js        最高画質の仕上げ（陰り・光のにじみ・階調）
js/rail.js        モノレールの路線と時刻表
js/vehicles.js    車・電車・駅
js/space.js       宇宙港・採掘船・隕石
js/mansion.js     豪邸
js/whales.js      クジラ
vendor/           three.js（同梱）
```
